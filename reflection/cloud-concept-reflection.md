# Cloud Computing Reflection

Before taking this course, I rarely considered how deeply cloud computing was woven into my daily routine. I soon realized that many applications I depend on—like Google Drive for file backup, Messenger for communication, and Canva for project design—are actually cloud services.

These platforms exemplify the Software as a Service (SaaS) model because they are accessible directly through a web browser or app without requiring software management or local installation. They also utilize the Public Cloud deployment model, as they are hosted by third-party providers and made available to millions of global users over the internet.

Beyond cloud delivery models, I gained an understanding of why Git and GitHub are essential for modern teamwork. In collaborative projects, conflicting updates or accidental file overwrites can easily disrupt progress. Git solves this by recording a comprehensive revision history, making it simple to restore previous versions whenever mistakes happen. GitHub complements Git by serving as a centralized workspace where team members can review work, track contributions, and stay organized.

Ultimately, this lesson helped me see that cloud technology is already an essential part of my digital life. Learning how cloud infrastructure operates alongside version control has given me a much clearer perspective on the tools IT professionals rely on daily—skills that will benefit my academic studies, future projects, and professional career.
